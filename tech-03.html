Windows 系统深度优化：C 盘清理与开机加速

工作室几台电脑跑久了都变慢、C 盘飘红。整理一套安全、可复现的优化流程，照着做不破坏系统。

一、先清真正占地方的

  • 设置 → 系统 → 存储 → 临时文件，勾选后清理；
  • 把下载、文档、桌面大文件迁到 D 盘，别堆 C 盘；
  • 用磁盘清理工具清理"以前的 Windows 安装"，能省下几个 G。

二、开机项只留必要的

任务管理器 → 启动，把打印机、云盘、更新助手之类全禁掉，只留输入法和显卡相关。开机速度立刻上来。

优化的原则：只关你确认没用的启动项和临时文件，注册表、系统服务不要乱删，出问题难恢复。

三、Defender 占资源时怎么办

跑切片、扫描这类大文件任务时，Windows Defender 实时扫描会拖慢速度。可以把工作文件夹加入"排除项"，让它别反复扫——比直接关掉系统服务更安全、也更稳。
