非程序员的 Git/GitHub 入门：把博客推上线的最小流程

博客第一次传完后，以后想更新，总不想每次都拖网页。记住下面这四行命令就够了，不用学全 Git。

只需要记住四步

  • git add . —— 把改动的文件都暂存；
  • git commit -m "更新说明" —— 记下这次改了什么；
  • git push —— 推到 GitHub；
  • 等一分钟，Pages 自动更新。
第一次用之前，先在装 Git 后配好用户名邮箱，并在 GitHub 上配好 SSH 或用登录凭证，否则 push 会要求输密码。

什么时候用网页上传 vs 命令行

改一两篇文章，网页拖文件最省事；一次改很多文件、或想留版本记录，用上面四行命令。两者混着用完全没问题。
