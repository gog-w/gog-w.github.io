本地跑大模型：显卡怎么选、成本怎么估

想把模型跑在自己机器上，最关键是显存。先想清楚你要跑多大的模型，再决定显卡，别反过来。

显存决定一切

  • 量化后的模型，大致按"模型参数量 × 量化位数"估算所需显存，留点余量；
  • 显存不够就降量化等级、或换更小的模型，别硬上，会爆内存；
  • 日常写文案、答问题，7B~14B 量化模型足够，不用追大参数。

值不值得本地跑

只是偶尔用、又不想折腾网络和额度，直接用 API 更省钱。本地跑的价值在于：数据不出本机、不用按 token 付费、能离线。

先借后买

先用现有机器 + 小模型跑通流程，确认真的高频用，再升级显卡。为"以后可能用得上"买高端卡，多半吃灰。
